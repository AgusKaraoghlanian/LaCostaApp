Los registros JSON contienen fecha, propuestas, selectores/punteros, evidencia breve, cobertura y métricas. Los antecedentes se conservan en `historial`. Una respuesta HTTP pública o robots permisivo no equivale a autorización para republicar contenido protegido.

No hay fotografías publicadas. Las imágenes web seleccionadas para OCR pasan por KV local con vencimiento de diez minutos y borrado al consumo/cancelación, sin crear medios publicables. La foto comercial de prueba se eliminó también del directorio temporal de verificación. Se conservaron únicamente fixtures de Wikimedia con licencias explícitas y atribución, fuera de public/: [material, autores y licencias](../../tests/fixtures/ocr/ATRIBUCION.md). Para habilitarlos falta registrar por archivo: titular o autorización/licencia, uso permitido, fuente, fecha, referencia y decisión editorial. Revocar una autorización deberá permitir retirar el archivo de las fichas y de los derivados publicados.

Facebook e Instagram quedan como enlaces de referencia; no existe conector autorizado de Meta en esta versión. La posible integración futura necesita revisar los permisos oficiales aplicables y autorizar la conexión, sin prometer acceso a cuentas o contenido restringidos.

# Costa a la carta

Guía gastronómica de bares y restaurantes de la costa argentina (empezando por el Partido de La Costa).

- `backend/`: la API nueva (Express + Prisma + PostgreSQL). Ver [ESTRUCTURA.md](ESTRUCTURA.md) para levantarla.
- `app/`: la versión anterior (React + Vite, API Hono, D1/SQLite local y motor Node), en migración.
- `demo/`: la demo original con 20 negocios ficticios. Es la referencia de apariencia.
- `docs/entrega/`: documentos de arquitectura y prompts de la entrega del 1 de noviembre de 2026.
